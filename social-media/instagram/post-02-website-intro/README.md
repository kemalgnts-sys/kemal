# GurbetDe Instagram — Gönderi #2: Site Tanıtımı ("GurbetDe nedir?")

Carousel formatında site tanıtım gönderisi. Lansman gönderisinin ardından
"Ben kimim → Ne sunuyorum → Nasıl kullanılır" akışının ikinci halkasıdır.

## Dosyalar

| Dosya | Boyut | Kullanım |
|-------|-------|----------|
| `gurbetde-intro-cover-1080.png` | 1080×1080 | Carousel kapak slaytı (1. slayt) |
| `slides.md` | — | 6 slaytın tam metinleri (2–6. slayt görselleri için) |
| `ready-to-post.txt` | — | Kopyala-yapıştır caption |
| `caption.md` | — | Caption + yayın notları |
| `hashtags.md` | — | Hashtag listesi |

## Yayın Adımları

1. Kapak görselini ve (üretildiğinde) 2–6. slayt görsellerini sırasıyla carousel olarak yükleyin.
2. `ready-to-post.txt` içeriğini caption alanına yapıştırın.
3. Lansman gönderisinden 1–2 gün sonra, hafta içi 18:00–21:00 (Almanya saati) arası yayınlayın.
4. Yayın sonrası ilk 2 saat yorumlara aktif yanıt verin.
